## Developer Certificate of Origin

Every commit must include a `Signed-off-by` trailer certifying the Developer
Certificate of Origin (DCO):

```text
Signed-off-by: Your Name <your.email@example.com>
```

Use `git commit -s` to add the trailer automatically. The DCO text is available
at <https://developercertificate.org/>.

## Pull requests

Please describe the user-visible behavior, tests run, and any third-party code
or assets added. Do not include credentials, private project data, generated
release artifacts, or files whose license is incompatible with this repository.

Contributors retain copyright in their contributions. The project receives the
license grant needed to distribute accepted contributions as part of ModMind
under `AGPL-3.0-only`.
